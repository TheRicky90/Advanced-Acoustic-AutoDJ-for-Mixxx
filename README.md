# Advanced-Acoustic-AutoDJ-for-Mixxx
An advanced JavaScript-based AutoDJ automation script for Mixxx DJ, originally based on Byron Xu's code, re-engineered to follow the empirical rules of acoustic power and harmonic mixing.Instead of basic linear volume fades, this script maps an entire 3-band equalizer rack and a 3-slot effects engine directly to the Mixxx GUI crossfader position.
